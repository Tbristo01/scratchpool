# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The summary below is binding for this repository; the full text at that link applies to anything it does not cover.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Expected behaviour

- Be kind, patient and constructive. Assume good intent.
- Give and accept feedback on the work, not the person.
- Respect people's time: clear reports, focused pull requests.
- Protect others' privacy, including credentials and org data in logs or screenshots.

## Unacceptable behaviour

- Harassment, insults, slurs, or sexualized language or imagery.
- Personal or political attacks and trolling.
- Publishing someone's private information without explicit permission.
- Any conduct that would reasonably be considered inappropriate in a professional setting.

## Scope

This applies in all project spaces (issues, pull requests, discussions, reviews) and when someone represents the project in public.

## Reporting and enforcement

Report conduct concerns privately to the **repository owner** ([@Tbristo01](https://github.com/Tbristo01)) through GitHub, for example via the owner's GitHub profile or, if the concern involves a security issue, through [private vulnerability reporting](https://github.com/Tbristo01/scratchpool/security/advisories/new). You can also use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) tools.

The repository owner will review every report promptly and fairly, and will respect the reporter's privacy. Consequences follow the Contributor Covenant enforcement ladder: correction, warning, temporary ban, permanent ban.
